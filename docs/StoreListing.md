## English (default locale)

### Short description (max 80 characters)

Inline page and selection translation in any Chromium browser.

### Full description

Helium Inline Translator keeps translations focused and fast:

- **Translates entire pages or selected snippets** inline, without popups or layout-breaking overlays.
- **Translates exactly what you select**, including part of a sentence or text node.
- **Customizable shortcuts** — defaults are `Alt + Shift + Q` for selections and `Alt + Shift + W` for full pages; change them at any time in the browser's shortcut settings.
- **Popup controls** for translate page, translate selection, revert, and live status.
- **Progress and cancel** for long pages, plus safe revert that leaves live content untouched.
- **Keeps up with dynamic pages** by translating newly added content and resetting cleanly after in-page navigation.
- **Works in 49 languages**, with favorites, quick search, light/dark themes, and a localized interface.
- **No analytics, ads, or tracking.** Text is sent to Google Translate only when you request a translation.

Press the shortcut again (or use Revert in the popup) to restore the original content. Preferences sync across signed-in devices via Chrome Sync. Built for people who translate frequently and value a clean reading experience.

### Promotional tagline

Translate without popups, keep the page clean.

### What's new in 1.2.0

- Popup actions, live translation status, progress, and cancel.
- Customizable keyboard shortcuts and more reliable batch translation.
- Embedded content inside iframes and open shadow roots is translated too.
